# PAWPAIR アーキテクチャ

## 目標の実フロー

~~~mermaid
flowchart LR
    Owner[飼い主フォーム]
    App[Reactアプリ]
    Firestore[(Firebase Spark<br/>Firestore)]
    Worker[Cloudflare Workers Free]
    Orca[OrcaRouter]
    Temp[一時メディア処理<br/>解析後破棄]
    Profile[性格パラメータと<br/>分析結果]
    Pair[全ペア採点<br/>n(n-1)/2]
    Optimize[部屋割り最適化]
    Operator[単一オペレーター<br/>確定]

    Owner --> App
    App -->|受付保存・read-back| Firestore
    App -->|名前・連絡先・音声を除外| Worker
    App -->|写真/動画一時入力| Temp
    Temp --> Worker
    Worker -->|実解析要求| Orca
    Orca -->|構造化応答| Worker
    Worker --> App
    App -->|分析結果保存| Firestore
    Firestore --> Profile
    Profile --> Pair
    Pair -->|全ペア完了後| Optimize
    Optimize --> Operator
    Optimize -->|提案保存| Firestore
    Temp -.解析後削除.-> Temp
~~~

AIがエラーを返した場合、Worker/アプリはエラーを表示し、固定結果・ローカル判定・疑似成功へ切り替えない。音声ファイルと動画内音声をOrcaRouterへ送らない。オペレーターが提案を確認してから確定する。

    Form --> App

この状態図は要件達成図ではない。Workerをフォームから呼び出す実動線、AI結果のFirebase保存、R2永続保存経路の除去、Firebase/Worker/OrcaRouterの実配備・実E2Eが未完了である。フォームは画像/動画をBlob URLでプレビューするが、分析は行っていない。現在のローカル変換をAI失敗時の成功フォールバックとして使わない。

## 構成・料金境界

| 部品 | 境界 |
|---|---|
| Firebase | Sparkのみ。FirestoreとHosting。Cloud Functions/Cloud Storage for Firebaseなし |
| AIプロキシ | Cloudflare Workers Freeのみ |
| OrcaRouter Secret | 再発行済みキーをWorker Secretへだけ格納。以前チャットに貼ったキーは禁止 |
| メディア | AI分析用の一時入力。永続R2保存なし |
| 利用者 | 単一利用者、固定URL |

実際の接続値、固定公開URL、実配備は未確認。詳細は [TASKS.md](../TASKS.md) と [実装設計書](実装設計書_Firebase版.md) を参照。
