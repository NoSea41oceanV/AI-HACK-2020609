# PawPals / PAWPAIR アーキテクチャ

更新日: 2026-09-22。基点 `6609e68`。実装・検証状態は [受入条件・証拠対応表](integration/pawpals-acceptance.md) を参照。

## サービス接続

~~~mermaid
flowchart LR
    Hosting[Firebase Hosting]
    App[Reactアプリ<br/>飼い主フォーム・スタッフ画面]
    Auth[Firebase Auth<br/>施設ログイン]
    DB[(Cloud Firestore<br/>施設・招待・受付・提案・観測)]
    Worker[Cloudflare Workers Free<br/>入力検証・秘密鍵保持]
    Orca[OrcaRouter<br/>構造化分析]
    Hosting -->|静的アプリ配信| App
    App <-->|施設認証| Auth
    App <-->|Rulesでアクセス制御・保存・読戻し| DB
    App -->|構造化入力・一時画像| Worker
    Worker <-->|AI解析| Orca
    Worker -->|検証済み応答| App
~~~

Firestoreを読み書きするのはReactアプリのRepository。Firebase Hostingは静的配信を担当し、OrcaRouterとFirestoreの直接接続はない。全ペア採点・部屋最適化はReactアプリ内のTypeScript処理であり、独立したクラウドサービスではない。生成済みPNGは旧説明用で、サービス接続と今回仕様の正本はこの図と確定設計書とする。

## 今回の業務フロー（追加部分を含む目標）

~~~mermaid
flowchart TD
    Login[施設ログイン・スタッフ選択]
    Invite[招待URL/QR発行<br/>既存発行者契約を維持]
    Intake[飼い主入力<br/>健康・社会化・行動6問・自由記述]
    AI[Worker / OrcaRouter<br/>7軸・根拠・信頼度]
    Profile[受付・分析・プロフィール保存]
    Select[対象日・当日対象犬を明示選択して保存]
    Rooms[施設別部屋設定を保存]
    Pair[選択対象の全ペア採点<br/>score%・hard block]
    Plan[部屋割り最適化]
    Proposed[最新proposedを保存<br/>旧proposedはsuperseded]
    Review[選択中スタッフが承認/却下]
    Audit[操作監査保存<br/>担当・日時・理由・元案]
    Manual[スタッフ手動観測の保存]
    Login --> Invite --> Intake --> AI --> Profile --> Select
    Login --> Rooms
    Select --> Pair
    Rooms --> Plan
    Pair --> Plan --> Proposed --> Review
    Review -->|confirmed / rejected| Audit
    Select -->|day_saved| Audit
    Rooms -->|rooms_saved| Audit
    Proposed -->|recalculated| Audit
    Manual -->|再計算| Pair
~~~

健康・社会化・実モック6問/7軸、日付付き対象、施設別部屋設定、4状態遷移と監査は今回の進行中要件である。この図だけで実装・配備済みとはしない。手動部屋編集と5分類は含めない。

## 将来カメラIFの境界

~~~mermaid
flowchart LR
    Manual[手動観測入力] --> Adapter[入力源・型・adapter境界]
    Future[将来カメラ入力源<br/>IFのみ・未接続] -.-> Adapter
    Adapter --> Record[ObservationRecord / operation event契約]

~~~

IF図は将来入力の契約範囲を示す。カメラ接続、15分監視、映像保持、通知送信を実装済みと示さない。実ログ・severity・ack・交流実績を捏造しない。

## 基点と配備の区別

基点は施設認証・招待・既存5軸・全ペア計算・提案/確定・手動観測を含み、モック統合のローカル検証記録がある。新しい要件の検証と公開配備は証拠待ち。旧公開デモの成功記録は、今回の公開配備完了を意味しない。

FirebaseはSpark、WorkerはFreeを維持。今回の設計同期は文書変更のみである。
