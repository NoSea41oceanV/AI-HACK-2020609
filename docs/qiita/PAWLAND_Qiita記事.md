# 「うちの子にも、気の合うお相手がいたらいいな」から始まった。犬の相性を考えるPAWLAND 🐶

「**うちの子にも、気の合うお相手が見つかったらいいのにな！**」

PAWLANDは、そんな気持ちから始まりました！🐶✨

ペットって、ただ一緒に暮らしている動物じゃないですよね。

毎日顔を合わせて、うれしい日も落ち込んだ日もそばにいてくれる、**大切な家族**です。

だからこそ、こんなことを考えることがあります。

> 「この子と気の合う友だちがいたら、もっと楽しい時間を過ごせるかも！」
>
> 「性格の合う子と出会えたら、新しい表情を見せてくれるかも！」

人には友だちやパートナーとの出会いがあるんだから、ペットにも、その子らしさに合った出会いがあってもいいんじゃないかな？

最初は、そんなペット好きの素朴な願いでした。

## ホテルに預けるとき、ちょっと心配になりませんか？ 🏨

そこからみんなで話しているうちに、もう一つの場面が浮かびました。

旅行や仕事で、愛犬をペットホテルや保育園へ預けるときです！

スタッフさんが大切に見てくれるって分かっていても、飼い主としてはやっぱりちょっと心配になりますよね。

- **ほかの犬と仲良く過ごせるかな**
- **怖い思いをしていないかな**
- **この子の苦手なことや、いつもの様子が伝わっているかな**

一方で、施設側にも同じ思いがあります。

「**預かった子たちに、できるだけ心地よく過ごしてほしい！**」

そのためには、犬の性格、遊び方、体格、ほかの犬への反応、その日の様子まで見ながら、どの子を一緒にするか考えなければなりません。

経験豊富なスタッフほど自然に判断できますが、その知識ってどうしても頭の中に残りがちです。

しかも、忙しい時間帯に何頭もの情報を見比べて、別のスタッフへ理由まで引き継ぐのは、決して簡単じゃありません。

だったら！

**飼い主が知っている「うちの子らしさ」と、施設で分かる「今日の様子」をつないで、判断を手伝う仕組みを作れないかな？**

そこで生まれたのが **PAWLAND** です！💡✨

## PAWLANDって、どんなもの？

PAWLANDは、犬の性格や行動を整理して、**ペットホテルや保育園の部屋割りをサポートするWebアプリ**です！

使い方はとってもシンプルです。

1. 施設が、飼い主専用の**登録URLまたはQRコード**を発行する
2. 飼い主が、愛犬の性格や遊び方、苦手なことなどを入力する
3. AIが回答や画像から、その子の特徴を整理する
4. PAWLANDが犬同士の相性と安全条件を確認し、部屋割り案を作る
5. スタッフが理由を見て、最後に判断する

飼い主がアクセスできるのは、施設から案内された登録フォームだけ。

施設側では「今日見る子」「プロフィール」「相性カルテ」「部屋割り案」をまとめて確認できます！

![飼い主向けの愛犬登録フォーム](https://raw.githubusercontent.com/NoSea41oceanV/AI-HACK-2020609/main/docs/qa/owner-form-mobile.png)

*飼い主向け画面：スマートフォンから、普段の性格・遊び方・注意事項などを登録できます。*

![施設スタッフ向けダッシュボード](https://raw.githubusercontent.com/NoSea41oceanV/AI-HACK-2020609/main/docs/qa/staff-dashboard.png)

*施設スタッフ向け画面：登録された犬の情報、全ペアの相性、部屋割り案をまとめて確認できます。画面内の犬はデモ用の架空データです。*

## 性格は、選びやすく。理由は、見返しやすく

飼い主さんに、難しい専門用語を入力してもらう必要はありません！

- 「初めて会う犬にはどう近づく？」
- 「おもちゃをほかの犬が取ろうとしたら？」
- 「楽しくなると、どんな様子になる？」

こんな感じで、普段の姿を思い出しながら選べる質問を中心にしました。

もちろん、選択肢だけでは表せない「うちの子らしさ」もありますよね。

そこで**自由記述や写真**も使って、AIが性格傾向や遊び方、注意点を整理します！

スタッフ側では、結果をただの点数で終わらせません。

相性カルテから、

- **どこが合いそうか**
- **どんな点に注意したいか**

を確認できるようにしています！

## AIに全部は決めさせません 🤖

開発中に一番悩んだのは、**AIにどこまで任せるか**でした。

最初は、

> 「性格も相性も部屋割りも、全部AIに考えてもらえばいいんじゃない？」

と思っていました。

でも、犬たちの安全に関わる判断を、理由の分からない答えへ丸投げするのは違います。

そこで、役割をはっきり分けました！

| 担当 | やること |
| --- | --- |
| **AI** | 飼い主の回答や画像から、性格・遊び方・注意点を整理する |
| **コード** | 全ペアの比較、同室不可、体格差、部屋の定員などを確認する |
| **スタッフ** | 提案と当日の様子を見て、最後に承認・見直しをする |

:::note warn
**AIは獣医師の代わりではありません。診断や安全保証をするものでもありません。**

PAWLANDは、スタッフが判断するための材料をそろえる**相棒**です。🤝✨
:::

## 相性が良くても、同じ部屋にできないことがある

よく遊ぶ犬同士でも、体格差が大きかったり、おもちゃを守ろうとする傾向があったりすれば、同じ部屋を避けたほうがいい場合があります。

そこでPAWLANDでは、まず**「同室不可」「部屋の定員」などの安全条件**を守ります。

そのうえで、遊び方や活動量などを比べます！

目の前の1組だけじゃなく、その日に預かる犬たちの組み合わせをまとめて確認してから、**全体の部屋割り**を考えるのもポイントです。

そして、安全な案を作れないときは、無理に答えを出しません。

:::note alert
安全条件を満たす部屋割りを作れない場合は、**「今回は割り当てられない」**と理由を返し、スタッフに判断を戻します。🛡️
:::

## システム構成

画面は **React / TypeScript / Vite**、データ保存は **Firebase Cloud Firestore**、公開には **Firebase Hosting** を使いました！

AI分析は、ブラウザから直接ではなく、**Cloudflare Workers**を経由して**OrcaRouter**へ送ります。

APIキーをブラウザへ置かず、AIへ送っていい項目もWorker側で確認するためです。

![PAWLANDのシステム構成図](https://raw.githubusercontent.com/NoSea41oceanV/AI-HACK-2020609/main/docs/architecture-overview-pawland.png)

*PAWLANDの実構成：飼い主・スタッフ向けWebアプリ、Firebase、Cloudflare Workers、OrcaRouterの責務とデータ境界。*

そして、特に気をつけたのが、**飼い主の個人情報**です！

氏名や連絡先は施設運営のためにFirestoreへ保存しますが、AI分析には送りません。

AIへ渡すのは、犬の性格や行動など、分析に必要な情報だけです。

動画も、元データや音声をそのまま送るわけではありません。ブラウザで取り出した**少数の静止画だけ**を使います。

写真や動画を永続保存するストレージも、今回の構成では使っていません。

:::note info
- **AIへ送るもの**：犬の性格・遊び方・注意事項・写真・動画から抽出した少数の静止画
- **AIへ送らないもの**：飼い主の氏名・連絡先・音声・元動画
:::

## 審査の5項目を、設計のチェックリストにした

AI HACK 2026で示された5つの評価項目は、発表資料の見出しとして使っただけじゃありません！

開発中のチェックリストとして使いました。

### 🔐 セキュリティ

APIキーをWorkerのSecretで管理して、飼い主の氏名・連絡先はAIへ送らないようにしました。

施設の画面と飼い主の登録画面も分けています！

### 💰 コストパフォーマンス

Firebaseの**Sparkプラン**とCloudflare Workersの**Freeプラン**を使って、必要な処理だけをAIへ任せました。

今後は、1登録あたりのAI利用量を実測して改善していきます！

### 🧱 信頼性・堅牢性

AIの回答が想定した形式でなければ、成功扱いにはしません。

さらに、安全条件をAIの文章で上書きできない構造にしました。

割り当て不能なら、無理な案を出さずに止まります！

### 🔄 自律

登録、AI分析、全ペア比較、部屋割り、当日の観察、再提案までを一つの流れにつなぎました！

ただし、**安全に関わる最終判断はスタッフ**が行います。

### ✨ アイデア・独創性

単発の性格診断で終わらせません！

飼い主の事前情報、施設での観察、相性、スタッフの判断をつないで、**「その子をもっと理解するためのデータ」**として積み重ねていきます。

:::note info
架空の犬2頭を使い、**登録 → AI分析 → 相性評価 → 部屋割り → スタッフの確定**まで、一連の実サービス接続フローを確認済みです。

公開デモには、画面や相性比較をすぐ確認できるよう**6頭分の架空サンプルデータ**も用意しています。
:::

実際の施設での使いやすさや効果については、これから現場で検証していきます。

## AIと一緒なら、私たちにも作れた

私たちは**3人チーム**です！

開発経験のあるメンバーもいれば、IT未経験から始めたメンバーもいます。

そして、AIハッカソンへの参加も初めてでした！

分からないことが出たらAIに聞いて、コードを書いて、動かして、失敗して、また直す。その繰り返しです！

とはいえ、AIが勝手に正解を作ってくれるわけではありません。

- **誰のために作るのか**
- **AIが間違えたらどこで止めるのか**
- **犬たちにとって本当に安心できるか**

そこは、私たち自身が何度も考えました。

AIは開発者の代わりじゃありません。

**一緒に悩んで、一緒に形にしてくれる相棒**なんだと感じています！✨

## いつか、「うちの子のお友だち」が見つかる場所へ 🌱

まずは、ペットホテルや保育園で、預かった犬たちが心地よく過ごせるようにすること！

そして、その先では、最初に思い描いていた

> **「うちの子と気の合うお相手を見つける」**

という体験にも広げたいと思っています。

施設で積み重なった性格や遊び方の情報を、飼い主にも役立つ形へつなげていく。

そうすれば、PAWLANDは単なる部屋割りツールではなく、ペットと飼い主、そして施設をつなぐ場所になれるかもしれません！

:::note warn
「気の合うお相手を見つける」飼い主向け機能や、実施設での継続運用は**将来構想**です。現時点のPAWLANDは、施設スタッフによる相性評価・部屋割り判断を支援するハッカソン版です。
:::
