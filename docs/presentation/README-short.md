## 生成と確認

- `build-short-pitch.mjs`: 同梱NodeとArtifact Toolで7枚を作成。最終出力を再インポートしてPNGにレンダーする。再生成時は `PITCH_FILENAME` で別名を指定。
- `export-short-pdf.py`: 確認済み画像から7ページPDFを生成。
- `build-flyer.py`: 埋込日本語フォントと既存犬画像を使い、A4営業チラシを生成。画像はプロジェクトのサンプル素材であり導入実績を示す写真ではない。

全ページを画像で確認。PPTXの構造・文字配置・編集可能な表/グラフ・月次売上と原価の合計を検査。PowerPointアプリでの表示確認、実際の読み上げリハーサル、アプリの機能テストは実施していない。

チラシは通常の1枚文書作成のため `routine_worker` に委任。現在のブランドと認証状態は読み取り調査のため `fast_scan` に委任。主担当が発表資料を再構成し、両成果物の整合性と表示を確認した。
