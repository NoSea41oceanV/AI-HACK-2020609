## 画面の根拠

https://pawpair-ai-hack-2026.web.app/demo を2026-09-22に撮影。6頭の架空データを表示する実システムの公開デモ。「今日の運営」と「相性カルテ」を掲載し、デモであることを明記。相性カルテの「7軸はこの計算に未適用」の表示も保持している。

`assets/` のPNGはこの資料の原画資料。ブラウザー全体キャプチャと、ヘッダー・余白を除いた業務領域の切り出しを保存。UIの内容は書き換えていない。実画面に残る旧名称はアプリ側の表示であり、今回の資料修正ではデプロイを実施していない。

## 生成と確認

- `build-short-pitch.mjs`: 同梱NodeとArtifact Toolで7枚作成。構造・配置・表の合計・編集可能な表/グラフを検査し、最終PPTXを再読込して全ページを画像確認。再生成時は `PITCH_FILENAME` に別名を指定。
- `export-short-pdf.py`: 確認したスライド画像から7ページPDFを生成。
- `build-flyer.py`: 実画面を用いてPDFを生成し、PNGへレンダーして確認。

画面取得元の公開デモをブラウザーで確認した。PowerPointアプリでの確認、読み上げリハーサル、アプリ機能テストは今回未実施。料金・売上・効果・原価は試算であり、過去のテスト記録は現在の再テスト結果ではない。

チラシの通常文書修正・確認を `routine_worker` に委任。親担当が実画面撮影、発表資料修正、全体整合性と成果物確認、Git共有を担当した。生成PDF/PPTXはコミットせず、原稿・生成元・画面原画のみ共有する。
