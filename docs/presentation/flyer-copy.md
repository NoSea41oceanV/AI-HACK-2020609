# PawPals 営業チラシ コピー

## 想定読者

ペットホテル、犬の保育園、デイケアなど、複数の犬を同時に預かる施設の責任者・現場スタッフ。

## メインコピー

部屋割りに悩む時間を、
犬と向き合う時間へ。

飼い主さまの回答と任意の写真・動画から、犬の特徴をAIが整理。全ペアの相性と施設の制約を見ながら、その日の部屋割り案までつなげます。

## 現場の困りごと

- 性格や注意点が、紙・予約台帳・スタッフの記憶に分かれている
- 犬が増えるほど、すべての組み合わせを比べるのが難しい
- 当日の様子が変わると、部屋割りを一から考え直す必要がある

## PawPalsがつなぐ3ステップ

1. 集める: 飼い主情報と任意の写真・動画由来の静止画から、AIが特徴を共通項目で整理
2. 比べる: 登録された全ペアを評価し、同室不可などの安全制約と部屋の定員を確認
3. 決める: 部屋割り案と判断理由を表示。当日の観測から再計算し、最後はスタッフが確定

## 提供価値

- 事前情報を一つの画面で確認
- 全ペアの相性と注意点を見落としにくく整理
- 部屋割り案と理由をスタッフ間で共有
- 犬の変化を観測として残し、その日の案へ反映

## 料金案

- 月額利用料: 10,000円 / 施設（税別）
- 初期導入料: 30,000円 / 施設（税別）
- 月200件までのAI解析を想定
- 導入条件は個別にご相談

## 安全上の考え方

PawPalsは判断を支えるツールです。犬の組み合わせや安全管理の最終判断は、施設スタッフが行います。
